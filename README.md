## B. Informasi Aplikasi
- *Nama Aplikasi:* QuizKu
- *Deskripsi Singkat:* Aplikasi kuis pilihan berganda untuk menguji wawasan pengguna dalam beberapa kategori. Aplikasi ini di lengkapi dengan sistem login anonim (Nama & Email), pelacakan riwayat skor kuis secara lokal, pembagian kategori soal, serta kustomisasi tema gelap dan terang untuk kenyamanan pengguna
- *Fitur-fitur yang Tersedia:*
1. **Autentikasi Pengguna (Login Anonim):** Pengguna masuk dengan mengisi Nama dan Email yang di lengkapi validasi form.
2. **Kuis Multi-Kategori:** Tersedia 3 kategori (Pengetahuan Umum, Matematikan Dasar, Sejarah Indonesia) dengan masing-masing berisi 10 soal pilihan berganda.
3. **State Management (Provider):** Memastikan progres jawaban, skor, dan nama pengguna tidak hilang saat layar dirotasi atau berpindah halaman.
  4. **Penyimpanan Riwayat Kuis:** Mencatat riwayat skor, kategori, dan waktu penyelesaian kuis secara lokal (in-memory).
  5. **Drawer Navigation (Menu Samping):** Menu untuk navigasi ke halaman Riwayat, mengubah Nama, mengganti Tema, dan Logout.
  6. **Dual-Theme (Dark Mode & Light Mode):** Fitur untuk mengubah tampilan aplikasi menjadi terang atau gelap.
  7. **Desain Responsif & Dinamis:** Ukuran elemen UI (ikon, teks, tombol) menyesuaikan ukuran layar perangkat (mobile, tablet, atau web).
  8. **Reusable Widget:** Komponen kartu jawaban (OptionCard) dipisah ke dalam file tersendiri agar kode lebih efisien.
